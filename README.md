# Web Scraping Project

**Source:** books.toscrape.com (practice website for scraping)
**Tools:** Python, requests, BeautifulSoup, pandas
**Data collected:** 100 books (title, price, rating, availability)

## Process
1. Inspected the HTML structure of the site.
2. Scraped 5 pages using requests and BeautifulSoup.
3. Cleaned the data (prices to numbers, ratings to a 1-5 scale, removed duplicates).
4. Saved the dataset as CSV and Excel.

## Files
- `web_scraping_books.ipynb`: full code and output
- `books_dataset.xlsx` / `.csv`: final dataset
